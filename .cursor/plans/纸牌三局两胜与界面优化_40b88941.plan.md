# 纸牌三局两胜与界面优化

## 1+2. 删除双人同屏，统一上方手牌大小

- [src/ui/config.ts](src/ui/config.ts)：`MatchConfig` 删除 `mode` 字段（非在线一律人机）；`playerFaction` 类型改为 `Faction | 'random'`（见第 4 项）。
- [src/ui/Lobby.tsx](src/ui/Lobby.tsx)：`GamePanel` 删除"模式"选项行，难度/阵营/先手直接展示；描述文案微调。
- [src/ui/CardGame/CardGameScreen.tsx](src/ui/CardGame/CardGameScreen.tsx)：删除热座分支——`handoff`/`pick2` 阶段、`firstPick`/`firstPicker` 交接逻辑、交接遮罩、认输弹窗的"哪一方认输"分支、`factionLabel`/`handFaceUp` 中 `!isAi` 分支。上方电脑手牌尺寸由 `'sm'` 改为 `'md'`，与原双人同屏一致（第 1 项）。
- [src/ui/BoardGame/BoardGameScreen.tsx](src/ui/BoardGame/BoardGameScreen.tsx)：`pickAiSlot` 不再返回 null，删除热座认输分支与 `aiSlot === null` 判断。
- 在线纸牌界面对方手牌已是 `'sm'`，同步改为 `'md'` 保持全局统一（[src/online/OnlineCardScreen.tsx](src/online/OnlineCardScreen.tsx)）。

## 3. 纸牌三局两胜（仅纸牌；和局不计胜场，加赛至一方先胜 2 局）

**人机（CardGameScreen）**
- 系列状态：`seriesWins {player, ai}`、局号；单局结束若无人达 2 胜 → 结果面板显示"第 X 局结束，5 秒后自动开始下一局"+ 倒计时 + "开始下一局"按钮（点击立即开局）；达 2 胜 → 显示"本轮最终获胜"面板 +"再来一轮"（重置系列）/"返回大厅"。
- 顶栏战绩改为显示本轮系列比分（第 X 局 · 你 n 胜 · 电脑 n 胜 · 和 n）。
- 玩家阵营整轮系列保持不变（随机也只在进入时抽一次）。

**在线（服务器权威）**
- [src/online/protocol.ts](src/online/protocol.ts)：`RoomView` 增加 `nextGameRemainingMs: number | null`（局间倒计时）与 `seriesOver: boolean`；`ClientMessage` 增加 `{ type: 'nextGame' }`；`wins` 语义改为"本轮系列比分"，新系列开始时清零。
- [server/roomManager.ts](server/roomManager.ts)：仅 `gameType === 'card'` 的房间启用系列——`onGameOver` 时若双方均未达 2 胜，进入局间状态并启动 5 秒定时器自动 `startGame`；任一玩家发 `nextGame` 立即开局；达 2 胜置 `seriesOver`，回到现有"双方准备再来一轮"流程（准备后重置系列比分）。局间有人离场/掉线时取消定时器。棋盘房间逻辑不变。
- [src/online/OnlineCardScreen.tsx](src/online/OnlineCardScreen.tsx)：结果面板区分"系列未结束"（倒计时 + 开始下一局按钮）与"系列已结束"（最终胜负 + 再来一轮/离开）。
- [server/__tests__/roomManager.test.ts](server/__tests__/roomManager.test.ts)：补系列流程测试（自动开局、nextGame 提前开局、2 胜结束、和局加赛）。

## 4. 阵营选择增加"随机"

- Lobby 纸牌面板阵营选项：执龙 / 执虎 / 随机；`'random'` 在 CardGameScreen 挂载时抽签一次，整轮系列生效。

## 5. 棋盘顶部信息重排（离线 + 在线棋盘界面同步修改）

- 标题行改为三列网格（左"← 返回大厅"、中"棋盘翻棋"、右空占位），保证标题与棋盘中线对齐；删除标题行的战绩与认输按钮。
- 状态行改为：先手块 | 战绩 | 后手块，三块整体居中；删除"连续 0/16 步无翻牌吃子"文字；"认输"小按钮放在状态行最右侧。
- 和棋预警改为弹窗：`quietMoves` 达到 10 与 14 时各弹一次"已连续 X 步无翻牌无吃子，达到 16 步将判和棋"，点"知道了"关闭。
- 样式调整在 [src/styles.css](src/styles.css)。

## 6. 极简规则页

- 新增极简规则内容（Markdown，与完整规则同目录）：核心一句话——1 吃 2、2 吃 3……7 吃 8，唯独 8 反吃 1；再各用三五行概括两种玩法的开局与胜负。
- [src/ui/RulesScreen.tsx](src/ui/RulesScreen.tsx)：顶部两个 tab——"极简规则"（默认）/"完整规则"，均用现有 ReactMarkdown 渲染。
- Lobby 底部按钮文字改为"1分钟掌握游戏规则"。

- 更新受影响的单元测试，`tsc`（前端 + 服务器）、全部 vitest、`npm run build` 通过；在线系列赛用 fake timers 测试覆盖。
